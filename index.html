Reflection

I would probably say that the trickiest close method for me was the Escape key because I had to make it so that it only closed the menu when the menu was open. When I was making the navigation, I ended up looking up how aria-expanded works with buttons, how JavaScript can toggle a class on the body element, and how transform: translateX() and transition created the sliding drawer effect. I also looked up how the backdrop can be hidden and shown through JavaScript. A place I have seen this outside of class is when I look at websites on my phone, where the hamburger icon opens the navigation from the right side. This pattern is useful because it keeps the navigation from taking up too much space on the page when it is not being used.
